Rainy: Audio player для Windows 10/11
=====================================

Запуск
  Дважды щёлкни Rainy.bat. Откроется окно плеера (Microsoft Edge без вкладок).
  Если Rainy.bat не заработал, попробуй Rainy_simple.bat.
  Ярлык на рабочий стол: ПКМ по Rainy.bat -> Отправить -> Рабочий стол (создать ярлык).
  Окно можно закрепить на панели задач.

Первый запуск
  1. Нажми "Выбрать папку с музыкой" и укажи папку. Подпапки сканируются сами.
  2. Теги и обложки (mp3, flac, m4a) подтянутся в фоне. Список обновляется по ходу.
  3. Если после перезапуска браузер просит подтвердить доступ к папке,
     нажми "Разрешить доступ" и выбери "Разрешать при каждом посещении".
  Папки: Настройки -> Библиотека -> "Папки с музыкой".

Горячие клавиши
  Пробел - пауза/пуск          Ctrl + стрелки влево/вправо - предыдущий/следующий
  Стрелки влево/вправо - перемотка     Стрелки вверх/вниз - громкость
  M - без звука                Esc - закрыть окно или полноэкранный плеер
  Мультимедийные клавиши клавиатуры и экран блокировки Windows тоже работают.

Синхронизация с телефоном через Яндекс.Диск
  1. Установи на компьютер программу Яндекс.Диск и дождись, пока папка Диска появится в проводнике.
  2. В плеере: Настройки -> Синхронизация -> "Создать файл в папке Диска" и выбери папку Яндекс.Диска.
     Файл rainy-sync.json появится в ней, программа Диска сама отправит его в облако.
  3. На телефоне: Настройки -> Синхронизация, логин Яндекса и пароль приложения
     (id.yandex.ru -> Безопасность -> Пароли приложений -> Файлы WebDAV). Файл на Диске должен лежать в корне.
  Синхронизируются плейлисты, избранное, история, скрытые треки, правки названий и обложек,
  счётчики прослушиваний и часть настроек. Песни не передаются. Треки сопоставляются по названию и исполнителю.
  После перезапуска браузер может попросить разрешить доступ к файлу: нажми "Синхронизировать сейчас".

Важно
  - Свёрнутое окно продолжает играть. Если ЗАКРЫТЬ окно, музыка остановится.
  - Файлы плеер не меняет. Удаление трека из меню удаляет файл с диска навсегда
    (браузер сначала спросит разрешение на запись).
  - Резервную копию с телефона (Настройки -> Резервная копия -> "только данные")
    можно загрузить здесь: плейлисты, избранное и статистика сопоставятся по названию и исполнителю.
  - Все данные плеера лежат в профиле браузера: %LOCALAPPDATA%\RainyPlayer
    Чтобы сбросить плеер полностью, закрой окно и удали эту папку.
